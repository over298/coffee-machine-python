# Coffee Machine in Python ☕

Projeto desenvolvido durante meus estudos de Python.

A aplicação simula uma máquina de café que permite escolher entre espresso, latte e cappuccino, verificando recursos disponíveis, processando moedas, calculando troco e registrando o lucro da máquina.

## Funcionalidades

- Escolha entre espresso, latte e cappuccino
- Verificação de ingredientes disponíveis
- Processamento de moedas
- Cálculo de troco
- Controle de lucro
- Relatório de recursos da máquina
- Tratamento de opção inválida
- Comando `off` para encerrar o programa

## Conceitos utilizados

- Variáveis
- Condicionais
- Loops
- Funções
- Dicionários
- Retorno de valores
- Lógica de programação
